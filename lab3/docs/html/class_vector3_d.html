Подробное описание

Трёхмерный вектор (x, y, z).

Поддерживает изменение длины на ±1% (++ / –), сложение и вычитание векторов, умножение и деление на число, сравнение векторов по длине. Ведёт подсчёт всех векторов, созданных с запуска программы.
